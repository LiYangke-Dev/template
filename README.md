## 🚀 如何使用

1. **选择模板**: 根据新项目的需求，在上述列表中找到对应的文件夹。
2. **复制**: 将整个文件夹复制到你的工作区（如 `D:/Projects/`）。
3. **重命名**: 将文件夹重命名为你的新项目名称（如 `prj-new-car`）。
4. **清理**: 删除旧的 `.git` 文件夹（如果有），重新初始化 Git 仓库。

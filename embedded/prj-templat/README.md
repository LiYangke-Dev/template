# 🚗 智能视觉巡线小车 (Smart Visual Car)

!<Version>
!<License>

## 📖 项目简介
这是一个基于 **STM32 + OpenCV** 的自动驾驶小车项目。
它能够通过摄像头实时识别赛道，利用 **PID算法** 控制舵机转向，实现高速平滑巡线。

## ✨ 核心功能
- **视觉识别**: 使用二值化与透视变换提取赛道中心线。
- **闭环控制**: 增量式 PID 算法控制舵机与电机。
- **上位机调试**: 通过串口实时上传数据到 PC 端波形显示。

## 🛠️ 技术栈
- **硬件**: STM32F407, OpenMV/K210, L298N
- **软件**: C (HAL库), Python (OpenCV)
- **算法**: 图像二值化, PID控制

## 📂 硬件连接
| 模块     | 引脚     | 说明       |
| :------- | :------- | :--------- |
| 摄像头   | PA9/PA10 | UART1 通信 |
| 电机驱动 | PA1/PA2  | PWM 调速   |
